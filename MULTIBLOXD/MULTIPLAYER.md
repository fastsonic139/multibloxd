# Real-player 1v1

1. Double-click `start-multiplayer.bat` (or run `npm start`).
2. Open `http://localhost:8080` in two browser windows or computers.
3. Enter the game and press **F6**. The first player waits in the queue; the second player is matched immediately.

For another computer on the same network, open `http://YOUR-COMPUTER-IP:8080`.
For worldwide internet play, follow `DEPLOY-WORLDWIDE.md`.

Press **F6** again to leave the queue or current match. The remaining player is automatically returned to the queue.
